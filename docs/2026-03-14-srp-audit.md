# SRP Audit — microgpt-lab

**Date**: 2026-03-14
**Scope**: Full codebase (model-rs/ + app/src/)
**Standard**: Single Responsibility Principle (ISO/IEC 25010 — Maintainability/Modularity)

---

## Rust — model-rs/

### Critical (not fixed — architectural constraint)

| File | Violation | Reason not fixed |
|---|---|---|
| `crates/microgpt-wasm/src/lib.rs` | God struct `WasmGpt` — 16 methods, 5 concerns (dataset, training, inference, introspection, sync) | `wasm_bindgen` requires single exported type. Splitting needs facade pattern. |

### High (not fixed — high risk / low ROI on toy model)

| File | Violation | Reason not fixed |
|---|---|---|
| `lib.rs` | `train_step_traced` duplicates `tensor_train_step` forward loop | Traced path needs inline access to intermediates. Refactor needs callback/visitor pattern in tensor_train.rs. |
| `src/tensor.rs` | `Tensor` mixes data, ops, graph, backward (280-line match) | Extracting `autograd.rs` would touch every op. High risk, no functional benefit on toy model. |
| `src/model.rs` | `Model` conflates weights + Adam state (`m_buf`/`v_buf` + `adam_step`) | Extracting `Adam` struct is clean but touches all 34 tests. Documented for future. |
| `src/tensor_model.rs` | Same — `TensorModel` conflates weights + Adam | Same as above. |

### Medium (fixed)

| File | Violation | Fix |
|---|---|---|
| `src/config.rs` | `TrainConfig` mixes optimizer params (`lr`, `beta1`) with inference params (`temperature`, `n_samples`) | Split into `TrainConfig` (optimizer) + `InferenceConfig` (sampling). |
| `crates/microgpt-wasm/src/training_trace.rs` | DTOs + selection policy + capture logic in one module | Extract DTOs to `trace_types.rs`, keep logic in `training_trace.rs`. |

### Medium (not fixed — architectural)

| File | Violation | Reason |
|---|---|---|
| `crates/microgpt-wasm/src/trace.rs` | `forward_with_trace` rewrites entire forward pass | Needs inline access to intermediates. Same pattern as train_step_traced — requires visitor/hook architecture. |

---

## Frontend — app/src/

### All violations fixed

| File | Violation | Fix |
|---|---|---|
| `hooks/use-model-worker.ts` | 5 responsibilities — dataset loading (`PRESETS.find` + `load`) coupled in hook | Extract dataset resolution to `lib/dataset-loader.ts`. Hook only sends messages. |
| `workers/model-worker.ts` | Validation utils + sampling algo mixed with Worker routing | Extract `lib/worker-utils.ts` (validation + type guards) and `lib/sampling.ts`. |
| `components/model-panel/model-panel.tsx` | 3 components + 1 hook in same file. `ConfirmResetDialog` is generic. | Extract to `components/ui/confirm-reset-dialog.tsx`. |
| `components/model-panel/params-panel.tsx` | `update()` enforces n_head constraint — business logic in render | Move constraint logic to `useParamsHandler` in model-panel.tsx. |
| `components/model-panel/loss-panel.tsx` | `buildChartOptions` + animation state mixed with UI composition | Extract to `hooks/use-loss-chart-options.ts`. |
| `lib/utils.ts` | `cn()` (generic) mixed with `modelColor`/`modelMuted` (domain) | Extract domain helpers to `lib/model-colors.ts`. |
